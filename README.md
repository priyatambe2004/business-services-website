# 🌐 Veda Technology – Business Services Website

A modern, responsive, and interactive company website developed to present **Veda Technology's** services, internship opportunities, training programs, and technology-focused learning tracks.

The project focuses on creating a professional online presence with an attractive user interface, smooth navigation, and interactive features using HTML, CSS, and JavaScript.

> **Project Note:** This is an independently developed informational website project inspired by Veda Technology's company information. It is not the official company website.

---

## 📌 Project Overview

The Veda Technology Website is designed to provide visitors with an organized overview of the company's IT services, internship programs, and learning opportunities.

The website combines a modern visual design with practical front-end functionality to make information easy to explore across different devices.

## 🎯 Project Objectives

- Create a professional and visually appealing company website.
- Present company information and IT services in a structured way.
- Highlight internship opportunities and available technology tracks.
- Provide a responsive experience across desktop, tablet, and mobile devices.
- Improve user interaction through JavaScript-based functionality.
- Practise front-end development and UI/UX design principles.

## ⚙️ How to Run the Project

Follow these steps to run the website locally:

1. Download or clone the repository.
2. Extract the project folder if downloaded as a ZIP.
3. Open the folder in Visual Studio Code.
4. Make sure all three files are in the same folder.
5. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
